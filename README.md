# Java_CICD_Pipeline
# CI_CD Pipeline for Java Application Deployment Using Jenkins.
# Automated CI/CD pipeline for a Spring Boot application using Jenkins, Docker, Amazon ECR, and Amazon EKS. The pipeline automatically builds the application, creates a Docker image, pushes it to ECR, and deploys the latest version to an EKS cluster.
# Note: This project was successfully implemented and tested on AWS (EC2, ECR, and EKS). Cloud resources were terminated after validation to avoid pay-as-you-go charges. Screenshots of each deployment stage are included as proof of execution.
